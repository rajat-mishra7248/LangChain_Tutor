# LangChain Tutor 🚀

A hands-on Python project focused on learning and exploring **LangChain** through practical Jupyter Notebook implementations.

This repository contains notebook-based examples and implementations to understand how LangChain works and how it can be used to build applications powered by Large Language Models (LLMs).

## 📌 Project Overview

The main goal of this project is to learn LangChain concepts through practical implementation rather than only theoretical knowledge.

It includes multiple Jupyter Notebooks covering different experiments, examples, and implementations.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/rajat-mishra7248/LangChain_Tutor.git
```

### 2. Open the Project Folder

```bash
cd LangChain_Tutor
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment (Windows)

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirement.txt
```

### 6. Start Jupyter Notebook

```bash
jupyter notebook
```

Open the notebooks in Jupyter and run the cells to explore the implementations.
